# Image Analysis & Canvas Specs

## Visual Properties
- **Canvas Base Color**: `#D8D8D8` (`rgb(216, 216, 216)`), 100% monochrome neutral gray (84.7% lightness).
- **Dot Matrix Tone**: `#9A9A9A` (darkened for clear optical contrast against `#D8D8D8`).
- **Dot Pitch**: `6px 6px` Cartesian grid.
- **Dot Radius**: `0.85px` with radial gradient anti-aliasing.
- **Interaction Rule**: Strictly NON-INTERACTIVE. Zero magnetic pull, zero cursor distortion, zero physics springs.
