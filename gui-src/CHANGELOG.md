# Changelog

All notable changes to PokéRescue Sentinel will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-26
### Added
- Initial workspace scaffold (React 19 + TypeScript + Vite + Tauri 2 shell).
- Monorepo package layout (`apps/desktop` and `packages/contracts`).
- Strongly typed domain contracts (`IncidentSummary`, `RouteRecommendation`, `ResponderUnitSummary`, `EvidenceRecord`, `ExternalProviderHealth`).
- Complete documentation suite across product, architecture, API, UI handoff, testing, and release guidelines.
