# Contributing to PokéRescue Sentinel

Thank you for contributing to PokéRescue Sentinel.

## Guidelines
1. **Design Authority**: The user owns the visual design. Do not invent design systems, components, or colors without explicit direction.
2. **Branching Model**: Use short-lived feature branches prefixed by `feat/`, `fix/`, `docs/`, or `refactor/`.
3. **Verification**: Always run `pnpm typecheck` and `pnpm test` prior to submitting changes.
4. **Contract Discipline**: Any changes to data models or API signatures must originate in `packages/contracts` and be documented under `docs/api`.
