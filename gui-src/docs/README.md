# PokéRescue Sentinel Documentation

Master index of project specifications, architectural plans, interface handoffs, and verification standards.

## Structure
- **Product (`docs/product/`)**: Overview, goals, personas, scope, and canonical glossary.
- **Architecture (`docs/architecture/`)**: Frontend layout, module boundaries, Tauri integration, dependency policies, and verification reports.
- **Decisions (`docs/decisions/`)**: Architectural Decision Records (ADRs).
- **UI Handoff (`docs/ui/`)**: User design handoff protocols, design token placeholders, and route registries.
- **API & Contracts (`docs/api/`)**: REST contracts, real-time event schemas, and error conventions.
- **Security & Privacy (`docs/security/`, `docs/privacy/`)**: Client boundaries, capability policies, and location privacy.
- **Testing & Quality (`docs/testing/`)**: Verification strategies, accessibility checklists, and performance budgets.
- **Release (`docs/release/`)**: Windows packaging guides and release checklists.
- **Roadmap (`docs/roadmap/`)**: Implementation phases and future integration registry.
