# Terms and Glossary

## Core Terminology
- **Incident**: A confirmed emergency event requiring tracking and response resources.
- **Road Segment Status**:
  - `VERIFIED_PASSABLE`: Confirmed clear and safe by authoritative evidence within freshness window.
  - `BLOCKED`: Known obstruction, collapse, flooding, or severe hazard.
  - `UNVERIFIED`: Reported or unknown status awaiting verification.
  - `STALE`: Previously verified status whose validity window has expired.
- **Evidence Record**: Multi-source data point (satellite, drone, responder report) validating a road or incident state.
- **Responder Unit**: Registered personnel, vehicle, or specialized team authorized to receive tasking.
- **Experimental Sensing**: Non-operational Wi-Fi CSI sandbox strictly isolated from rescue routing and triage decisions.
- **Tauri Shell**: Native desktop wrapper running the React frontend inside a secure Webview on Windows.
