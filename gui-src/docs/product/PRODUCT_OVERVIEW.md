# Product Overview — PokéRescue Sentinel

## Vision
PokéRescue Sentinel is a disaster-response command-center desktop application designed for emergency coordinators, incident managers, and field dispatchers. It provides unified operational awareness during crisis events.

## Target User Base
- Incident commanders coordinating regional resources.
- Logistics and dispatch officers planning verified responder transit.
- Medical and shelter facility operators updating capacity.
- Authorized field team leaders reporting observations.

## Core Capabilities (Planned)
1. **Incident Awareness**: Real-time event logging, hazard zones, and severity triage.
2. **Verified Routing**: Passable route planning grounded in multi-source verified evidence.
3. **Responder Tracking**: Authorized location updates and telemetry.
4. **Drone & Rover Observations**: Sensor feed aggregation and incident media evidence.
5. **Offline Operations**: Local caching and peer-to-peer sync during network blackouts.
6. **Isolated Wi-Fi Sensing Lab**: Experimental non-operational signal analysis sandbox.
