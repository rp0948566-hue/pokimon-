# Scope and Non-Goals

## In Scope (Current Scaffold Phase)
- React 19 + TypeScript + Vite monorepo workspace configuration.
- Tauri 2 Windows desktop packaging scaffolding and minimal Rust shell.
- Typed contract packages under `packages/contracts`.
- Route, page, feature, and component directory hierarchy with documented purposes.
- Design handoff documents for user visual styling.

## Deferred (Future Phases)
- Visual styling implementation (colors, typography, component skins) — owned by the user.
- Native Rust domain services, disaster routing algorithms, and database storage.
- Live WebSocket / SSE real-time streaming connections.
- Mapbox / Leaflet / MapLibre tile rendering engines.
- Operational hardware integration (drones, rovers, RF receivers).
- Operational deployment to Windows production environments.
