# Personas and Roles

## 1. Incident Commander
- **Context**: Regional emergency operations center (EOC).
- **Needs**: High-level map awareness, resource allocation, aggregate statistics, and critical incident approval.
- **Permissions**: Full read/write, dispatch authorization, scenario management.

## 2. Dispatcher / Logistics Lead
- **Context**: Operations room desktop station.
- **Needs**: Verified road passability, vehicle status, fuel/medical supplies, and route calculation.
- **Permissions**: Route calculation, team assignment, evidence submission.

## 3. Field Team Leader (Future Mobile/PWA)
- **Context**: Rescue vehicle or forward base.
- **Needs**: Turn-by-turn verified directions, team check-in, hazard obstacle reporting, offline caching.
- **Permissions**: Status check-in, field report submission, offline map viewing.

## 4. Systems Administrator
- **Context**: IT / technical operations.
- **Needs**: API connectivity, Tauri capability monitoring, offline database synchronization, provider health.
- **Permissions**: Configuration management, log auditing, diagnostic tools.
