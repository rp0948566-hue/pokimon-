# Screen and Route Inventory

All routes are scaffolded as neutral placeholders awaiting visual screens:

| Route Path | View Name | Primary Function |
| :--- | :--- | :--- |
| `/` | `OverviewPage` | Situational command dashboard and summary KPIs. |
| `/incidents` | `IncidentsPage` | Active incident triage and event timeline. |
| `/map` | `MapPage` | Interactive geospatial overview of emergency theatre. |
| `/routing` | `RoutingPage` | Verified route calculation and road evidence inspection. |
| `/teams` | `TeamsPage` | Responder units, equipment, and check-in status. |
| `/facilities` | `FacilitiesPage` | Hospitals, shelters, and forward supply hubs. |
| `/drone-rover` | `DroneRoverPage` | Autonomous and teleoperated observation feeds. |
| `/sensing-lab` | `SensingLabPage` | Isolated Wi-Fi CSI experimental simulation lab. |
| `/reports` | `ReportsPage` | Multi-source evidence records and situational reports. |
| `/voice-copilot`| `VoiceCopilotPage`| Dispatch voice guidance and audio transcriptions. |
| `/data-sources`| `DataSourcesPage` | External provider status and data ingestion health. |
| `/offline-status`| `OfflineStatusPage`| Local mesh sync, cached tile status, and storage. |
| `/settings` | `SettingsPage` | Configuration, capabilities, and system diagnostics. |
