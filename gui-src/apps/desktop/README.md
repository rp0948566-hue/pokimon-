# PokéRescue Sentinel — Desktop Client App

## Role
This application package represents the React + TypeScript frontend shell for PokéRescue Sentinel, wrapped in a Tauri 2 desktop shell for Windows packaging.

## Commands
```bash
# Run local Vite development server
pnpm dev

# Type check TypeScript
pnpm typecheck

# Production web build
pnpm build

# Launch Tauri development desktop window
pnpm tauri dev
```
